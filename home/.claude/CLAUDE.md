# Preferences for every Claude Code session

- Explain Linux concepts in plain language. Avoid unexplained jargon; say what a tool or setting does in everyday terms.
- Clean up temporary files when done: once a task or issue is resolved, delete the scripts, compiled helpers, screenshots, logs and other files you created along the way, and say what you removed. Keep only files that are part of something that now works.
- Use full paths instead of changing directories (no `cd dir && ...`). Changing directories moves the session's working directory, which then shows up in places like notifications.
